# Design references

Mood references for the Qubit Arena client. They show the look we want (dark space, neon frames, glowing nodes, gate cards).

**They are not specs.** Several images contain game content that is wrong for our rules (gate effects, end-zone sides, CNOT).
Build from [../ui-spec.md](../ui-spec.md); its §15 lists every difference. Do not ship these PNGs inside the app.
